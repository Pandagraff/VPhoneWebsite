# VPhoneWebsite
A Mockup website for my Human and Computer Interaction (HCI) Lab Project in Semester 2.

# FEATURES
This website features a register and login page. Once logged in, the website consists of a Home, Products, Promos, and About Us page. Users can browse and see the item catalogue.


**Note**: The contents of this mockup website are strictly for testing and educational purposes, serving as a mockup only, purely for a UI/UX design. This website is not for commercial use, and will not be updated to include actual promotional material.
